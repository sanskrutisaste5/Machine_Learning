# Case Study 01: Ball Classification

## Objective

The objective of this case study is to classify balls based on their given features using a Machine Learning classification algorithm.

## Description

In this case study, a dataset containing ball features is used to predict the type/class of the ball.

The model learns from the given training data and predicts the class of a new ball based on its features.

## Algorithm Used

* Decision Tree Classifier
* Python
* Scikit-learn

## Features

The model uses the following features:

* Weight
* Surface/Other given feature

## Dataset

The dataset is provided directly in the Python program as a list of values.

## Implementation

The classification model is implemented using the `DecisionTreeClassifier` from Scikit-learn.

## How to Run

Open the terminal inside this folder and run:

```bash
python Ball_Classification.py
```

## Output

The program predicts the class/type of the given test ball based on the trained Machine Learning model.

## Technologies Used

* Python
* Scikit-learn

## File

`Ball_Classification.py` – Contains the complete implementation of the Ball Classification case study.
